# 01 · 群的定义

> 这是一则短笔记，用来把定义钉牢。例子与定理的完整讨论见教材。

## 定义

设 \(G\) 是一个非空集合，\(\cdot\) 是 \(G\) 上的一个二元运算（也就是说，对任意 \(a,b\in G\)，乘积 \(a\cdot b\) 仍然在 \(G\) 中）。称 \((G,\cdot)\) 是一个**群**，如果下列三条成立：

1. **结合律。** 对任意 \(a,b,c\in G\)，\((a\cdot b)\cdot c = a\cdot(b\cdot c)\)。
2. **单位元。** 存在 \(e\in G\)，使得对任意 \(a\in G\)，都有 \(e\cdot a = a\cdot e = a\)。
3. **逆元。** 对每个 \(a\in G\)，存在 \(a^{-1}\in G\)，使得 \(a\cdot a^{-1} = a^{-1}\cdot a = e\)。

关于「封闭性」：有的书把它单独列为第 0 条。它其实已经写在「\(\cdot\) 是 \(G\) 上的运算」这句话里，不必再算作一条额外公理。

若还满足对任意 \(a,b\in G\) 都有 \(a\cdot b = b\cdot a\)，则称 \(G\) 是**交换群**或**阿贝尔群**。

常用两种写法：

- 乘法写法：运算写作 \(ab\)，单位元写作 \(e\) 或 \(1\)，逆元写作 \(a^{-1}\)，幂写作 \(a^n\)。
- 加法写法（多用于交换群）：运算写作 \(+\），单位元写作 \(0\)，逆元写作 \(-a\)，倍数写作 \(na\)。

## 两个立刻该证的事实

**单位元唯一。** 若 \(e\) 与 \(e'\) 都是单位元，则 \(e = e\cdot e' = e'\)。

**每个元素的逆元唯一。** 若 \(b,c\) 都是 \(a\) 的逆，则
\[
b = b\cdot e = b\cdot(a\cdot c) = (b\cdot a)\cdot c = e\cdot c = c.
\]
因此把「那个」逆元记作 \(a^{-1}\) 是合法的。

由此还可推出（请自行补细节）：\((a^{-1})^{-1}=a\)，以及 \((ab)^{-1}=b^{-1}a^{-1}\)（注意顺序）。在群里左右消去律都成立：若 \(ax=ay\) 则 \(x=y\)；若 \(xa=ya\) 则 \(x=y\)。

有的书用「结合 + 左单位元 + 左逆」作为定义，再证明它们其实给出双边单位元与双边逆。这与上面的定义等价，但第一步要仔细一点；初学时用双边定义更省事。

## 几个例子与一个非例子

- \((\mathbb{Z},+)\) 是交换群：单位元 \(0\)，\(n\) 的逆元是 \(-n\)。
- 整数模 \(n\) 的剩余类对加法成群，记作 \(\mathbb{Z}/n\mathbb{Z}\) 或 \(\mathbb{Z}_n\)（后者在不同书里可能表示 \(p\)-进整数，初学时最好用 \(\mathbb{Z}/n\mathbb{Z}\)）。
- 集合 \(\{1,2,\ldots,n\}\) 上的全体双射对映射合成成群，叫做**对称群** \(S_n\)。当 \(n\ge 3\) 时它不交换。
- 正多边形的刚性对称对合成成**二面体群**。
- 数域 \(F\) 上 \(n\) 阶可逆矩阵对乘法成群 \(\mathrm{GL}_n(F)\)，一般也不交换。
- **非例子：** \((\mathbb{N},+)\)（若 \(\mathbb{N}\) 从 \(0\) 起，则正整数没有逆元；若从 \(1\) 起，则连单位元都没有）。普通整数对乘法也不成群（\(0\) 没有逆，且正整数乘法的逆不必是整数）。

由一个元素 \(a\) 反复乘（或加）及其逆生成的集合是循环群的原型；细节见下一阶段「子群与循环群」。

## 建议你现在就做的练习

1. 写出单位元唯一、逆元唯一的证明，不看上面的三行。
2. 验证 \(\{1,-1,i,-i\}\) 对复数乘法成群；它与哪个「更抽象」的群同构？（同构的精确定义稍后才出现，这里先凭表来猜。）
3. 在 \(S_3\) 里找两个元素 \(\sigma,\tau\)，使 \(\sigma\tau\neq\tau\sigma\)。
4. 说明「有限非空集合上的一个结合运算，若左右消去律都成立，则它成群」——这是有限群的一个常用等价定义，证明可放到学完背景之后再做；先尝试看懂要证什么。
