# Macauley《Visual Group Theory》幻灯片非官方中译本

这是 Matthew Macauley（Clemson University）Math 4120 课程章节幻灯片的**非官方中译本**，仅供学习对照，**并非官方版本或官方中文版**。

原讲义来自 2020 年夏季课程材料，并配套 YouTube 视频课 *Visual Group Theory*。原文以 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 发布；本译本是其演绎作品，同样以 CC BY-NC-SA 4.0 发布。转载或改编须署名原作者 Matthew Macauley 与本译本说明，不得用于商业目的，并以相同许可分享。

- 原课程页：<https://www.math.clemson.edu/~macaule/classes/m20_math4120/>
- 许可说明索引：<https://www.math.clemson.edu/~macaule/youtube.html>
- 配套视频：[YouTube 播放列表（43 讲）](https://www.youtube.com/playlist?list=PLwV-9DG53NDxU337smpTwm6sef4x-SCLv)
- 英文原幻灯片本地副本：[pdfs/macauley-vgt/](../../pdfs/macauley-vgt/)

每份中译 PDF 先有一页许可与署名说明，随后每一页原幻灯片对应一页：上方是原幻灯片图像（保留凯莱图、照片与表格），下方是简体中文译文。页脚标明原幻灯片页码，并写有「非官方中译本・CC BY-NC-SA 4.0」。公式、群名与记号尽量保持原样。译文如有错漏，一律以原幻灯片为准。

同名的 `.md` 文件是便于在 GitHub 上阅读的纯文字对照，不含插图。重新编译可运行同目录下的 `build_zh_pdf.py`（依赖 typst 与已渲染的幻灯片图像）。中间产物放在 `_build/`，已列入仓库 `.gitignore`，请勿提交。

只翻译了作者本人、以 CC BY-NC-SA 4.0 发布的 7 份章节幻灯片（共 378 页）。**没有**翻译 Carter《Visual Group Theory》样章、Dana Ernst 2009 年讲义、Janet Chen 的魔方短文，也没有翻译课程大纲。
