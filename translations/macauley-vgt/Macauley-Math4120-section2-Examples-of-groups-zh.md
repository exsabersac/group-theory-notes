## 第 4 页 / 37

**循环群**

**定义**
群 $G$ 的 *阶* 是 $G$ 中互不相同元素的个数，记作 $|G|$。

$n$ 阶循环群（即 $n$ 个旋转）记作 $C_n$（有时也记作 $ZZ_n$）。

例如，上一页那些对象的对称群分别是 $C_3$（硼酸）、$C_4$（风车）和 $C_10$（辣椒）。

**说明**
另一种记号 $ZZ_n$ 来自于：$C_n$ 的二元运算不过就是模加法。要在 $ZZ_n$ 中把两个数相加，先把它们作为整数相加，再除以 $n$，取余数。

例如，在 $ZZ_6$ 中：$3 + 5 equiv_6 2$。“3 次喀哒 + 5 次喀哒 = 2 次喀哒”。（若语境清楚，我们甚至可以写 $3 + 5 = 2$。）

**循环群：加法写法**

写出循环群元素的一种常见方式，是使用整数 $0, 1, 2, dots, n-1$，其中

- $0$ 是单位元
- $1$ 是单次逆时针“喀哒”。

注意，集合 ${0, 1, dots, n-1}$ 在模 $n$ 加法下是封闭的。也就是说，若把该集合中任意两个数（模 $n$）相加，结果仍是该集合中的成员。

**循环群：乘法写法**

下面是循环群的另一种自然记号。若 $r$ 是一个生成元（例如旋转 $2 pi \/ n$），则我们可以把这 $n$ 个元素记作

$1, r, r^2, dots, r^(n-1)$。

可以把 $r$ 想成复数 $e^(2 pi i \/ n)$，而群运算就是乘法！

注意 $r^n = 1$，$r^(n+1) = r$，$r^(n+2) = r^2$，等等。你是否再次看到了模加法的影子？下面是一些凯莱图，使用典范生成元 $r$。

**小结**
在这一设定下，循环群可以看成集合 $C_n = { e^(2 pi i k \/ n) mid(|) k in ZZ }$，运算为 $times$。（乘法）单位元是 $1$。

## 第 7 页 / 37

**关于循环群的更多说明**

我们对循环群的一种记号是“加法的”，另一种是“乘法的”。这并不改变真正的群，只改变我们的记号选择。

**注记**
（唯一的）无限循环群（用加法写法）是 $(ZZ, +)$，即整数加法群。若用乘法记号，无限循环群是

$G = angle.l r mid(|)  angle.r = { r^k : k in ZZ }$。

对无限循环群 $(ZZ, +)$，只有 $1$ 或 $-1$ 可以充当生成元。（除非我们使用多个生成元，而这通常没有意义。）

**命题**
${0, 1, dots, n-1}$ 中任何与 $n$ 互素的数都能生成 $ZZ_n$。

例如，$1$ 与 $5$ 生成 $ZZ_6$，而 $1, 2, 3, 4$ 都能生成 $ZZ_5$。也就是说，

$ZZ_6 = angle.l 1 angle.r = angle.l 5 angle.r$，$ZZ_5 = angle.l 1 angle.r = angle.l 2 angle.r = angle.l 3 angle.r = angle.l 4 angle.r$。

回想：上面的记号并不是表现，它只表示“由……生成”。

## 第 11 页 / 37

**轨道**

**定义**
元素 $g in G$ 的 *阶*，记作 $|g|$，是其轨道的大小。也就是说，$|g| := |angle.l g angle.r|$。（回想：$G$ 的阶定义为 $|G|$。）

注意，在任何群中，$e$ 的轨道都只是 ${e}$。

一般地，元素 $g$ 的轨道是集合

$angle.l g angle.r := { g^k : k in ZZ }$。

正如我们在有限循环群中已经看到的，这个集合未必是无限的。

我们允许负指数，不过这只在无限群中才真正要紧。

一种思考方式是：元素 $g$ 的轨道，就是你通过把 $g$ 或其逆做任意多次所能到达的那些元素的汇集。

**注记**
在任何群 $G$ 中，元素 $g in G$ 的轨道是一个“坐落在” $G$ 内部的循环群。这是 *子群* 的一个例子，我们稍后会更详细地研究。

回想：若动作的次序无关紧要（即这些动作可交换），则群是 *阿贝尔的*（得名于 Niels Abel，阿贝尔）。下面是正式的数学定义。

**定义**

**二面体群**

循环群刻画只有旋转对称的二维对象，而二面体群刻画既有旋转对称又有反射对称的二维对象。

正多边形具有旋转对称与反射对称。刻画正 $n$ 边形对称的二面体群记作 $D_n$。

$C_n$ 中的所有动作也都是 $D_n$ 的动作，但还有更多。群 $D_n$ 含有 $2 n$ 个动作：

- $n$ 个旋转
- $n$ 个反射。

不过，我们只需要两个生成元。下面是一种可能的选择：

1. $r =$ 逆时针旋转 $2 pi \/ n$ 弧度。（单次“喀哒”。）
2. $f =$ 翻转（固定一条对称轴）。

下面是写出 $D_n$ 的 $2 n$ 个动作的一种（还有许多种）方式：

$D_n = { e, r, r^2, dots, r^(n-1), f, r f, r^2 f, dots, r^(n-1) f }$，

其中前一半是旋转，后一半是反射。

**二面体群的凯莱图**

**事实**

**定义**

## 第 28 页 / 37

**对换**

*对换* 是交换两个对象、并固定其余对象的置换，例如把 $i$ 与 $j$ 对调（见原图）。

用轮换记号，对换不过是一个 2-轮换，例如 $(i j)$。

**定理**
群 $S_n$ 由对换生成。

直观上，这意味着每一个置换都可以通过依次交换成对的对象来构造。

换句话说，若 $n$ 个人站成一排，而我们想把他们重排成某种别的次序，我们总可以依次让成对的人交换位置来做到这一点。

事实上，我们只需要相邻对换就能生成 $S_n$：

$S_n = angle.l (1 2), (2 3), dots, (n-1 space n) angle.r$。

尽管 $S_n$ 中的每个置换都可以写成对换的乘积，这样做的方式可能有许多种。

例如：

$(1 3 2) = (1 2)(2 3) = (1 2)(2 3)(2 3)(2 3) = (1 2)(2 3)(1 2)(1 2)$。

**定理**
一个固定置换写成对换乘积时，对换个数的奇偶性是唯一的。

也就是说，一个固定的置换要么可以写成偶数个对换，要么可以写成奇数个对换，但不能两种都是！

于是我们有 *偶置换* 与 *奇置换* 的概念。

**定理**
$S_n$ 中恰好一半的置换是偶的，它们构成一个群，称为 *交错群*，记作 $A_n$。

**凯莱定理**

任何构成群的置换集合都称为一个 *置换群*。

凯莱定理说：可以用置换来构造任意有限群。

换句话说，每一个群都与某个置换群具有相同的结构（我们说它们“同构”）。

**警告！**
我们并不是说每一个群都同构于某个对称群 $S_n$。而是：每一个群都同构于某个对称群 $S_n$ 的一个 *子群*——也就是 $S_n$ 中本身也构成群的一个子集。

**问题**
给定一个群，我们如何把它与一组置换联系起来？

**凯莱定理**

直观上，两个群同构是指它们具有相同的结构。

两个群是同构的，如果我们能为它们各自构造看起来完全相同的凯莱图。

**凯莱定理**
每一个有限群都同构于一组置换。

我们的算法展示了群元素与置换之间的一一对应。

不过，我们尚未证明：这些相应的置换构成一个群，也尚未证明所得的置换群与原来的群具有相同的结构。

需要证明的是：第 $i$ 行所对应的置换，再接上第 $j$ 列所对应的置换，其结果就是原表中第 $i$ 行第 $j$ 列那个格子所对应的置换。（习题。）
