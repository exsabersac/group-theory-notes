== 一点历史，以及对五次方程的追寻

二次公式是众所周知的。它给出二次多项式 $a x^2 + b x + c = 0$ 的两个根：

$x_(1,2) = (-b plus.minus sqrt(b^2 - 4 a c)) / (2 a)$。

三次与四次多项式也有公式，但非常复杂。多年来，人们想知道是否存在五次公式。谁也找不到。

在 19 世纪 30 年代，19 岁的政治活动家 Évariste Galois（伽罗瓦）在没有任何正规数学训练的情况下，证明了这样的公式并不存在。

他发明了群的概念来解决这个问题。

在 20 岁时被挑战进行一场他自知会输掉的决斗之后，伽罗瓦把生命的最后几天用来匆匆写下他所发现的一切。

在最后一封信中伽罗瓦写道：“我希望以后会有一些人，发现把这一团乱麻解读出来对他们是有益的。”

Hermann Weyl（1885–1955）这样描述伽罗瓦的最后一封信：“若以其中思想的新颖与深刻来评判，它也许是全人类文献中最有分量的一篇文字。”群论这一领域由此诞生！

== 算术

大多数人第一次接触数学，是以计数的形式。

起初，我们只知道自然数 $NN = {1, 2, 3, dots}$，以及如何把它们相加。

不久之后，我们学习如何相减，并了解负数。到了这一步，我们就有了整数 $ZZ = {dots, -2, -1, 0, 1, 2, dots}$。

然后，我们学习如何除数，并被引入分数。这就把我们带到有理数 $QQ = {a / b mid(|) a, b in ZZ, b eq.not 0}$。

尽管还有其他数（无理数、复数等等），做基本算术并不需要它们。

### 关键点
要做算术，我们至少需要有理数。

%%% PAGE 4
== 域

### 定义
一个带有加法与乘法运算的集合 $F$ 是一个 *域*，如果下列三个条件成立：

- $F$ 在加法下是一个阿贝尔群。
- $F without {0}$ 在乘法下是一个阿贝尔群。
- 分配律成立：$a(b + c) = a b + a c$。

### 例子
- 下列集合是域：$QQ$、$RR$、$CC$、$ZZ_p$（$p$ 为素数）。
- 下列集合不是域：$NN$、$ZZ$、$ZZ_n$（$n$ 为合数）。

### 定义
若 $F$ 与 $E$ 是域且 $F subset E$，我们说 $E$ 是 $F$ 的一个 *扩张*。

例如，$CC$ 是 $RR$ 的扩张，而 $RR$ 是 $QQ$ 的扩张。

在这一章中，我们将探索一些更不寻常的域，并研究它们的自同构。

%%% PAGE 5
== $QQ$ 的一个扩张域

### 问题
含有 $sqrt(2)$ 的、$QQ$ 的最小扩张域 $F$ 是什么？

这个域必须包含我们能从 $sqrt(2)$ 出发、通过求和、求差与求商得到的所有数。例如，它必须包括：$-sqrt(2)$、$1\/sqrt(2)$、$6 + sqrt(2)$、$(sqrt(2) + 3\/2)^3$、$sqrt(2) \/ (16 + sqrt(2))$ 等等。

不过这些都可以化简。例如，$(sqrt(2) + 3\/2)^3$ 可以写成有理数加上有理数乘以 $sqrt(2)$ 的形式。

事实上，所有这些数都可以写成 $a + b sqrt(2)$，其中 $a, b in QQ$。

### 关键点
含有 $sqrt(2)$ 的、$QQ$ 的最小扩张称为“$QQ$ 添加 $sqrt(2)$”，记作：

$QQ(sqrt(2)) = {a + b sqrt(2) : a, b in QQ}$。

%%% PAGE 6
== $QQ(i)$：$QQ$ 的另一个扩张域

### 问题
含有 $i = sqrt(-1)$ 的、$QQ$ 的最小扩张域 $F$ 是什么？

这个域必须包含 $-i$、$i\/2$、$6 + i$、$(i + 3\/2)^3$、$i \/ (16 + i)$ 等等。

与前面一样，我们可以把它们都写成 $a + b i$，其中 $a, b in QQ$。因此，域“$QQ$ 添加 $i$”是

$QQ(i) = {a + b i : a, b in QQ}$。

### 注记
- $QQ(i)$ 比 $CC$ 小得多。例如，它不含 $sqrt(2)$。
- $QQ(sqrt(2))$ 是 $RR$ 的子域，但 $QQ(i)$ 不是。
- $QQ(sqrt(2))$ 含有 $f(x) = x^2 - 2$ 的全部根。它称为 $f(x)$ 的 *分裂域*。类似地，$QQ(i)$ 是 $g(x) = x^2 + 1$ 的分裂域。

%%% PAGE 7
== $QQ(sqrt(2), i)$：$QQ$ 的另一个扩张域

### 问题
同时含有 $sqrt(2)$ 与 $i = sqrt(-1)$ 的、$QQ$ 的最小扩张域 $F$ 是什么？

我们可以分两步来做：

1. 把多项式 $x^2 - 2$ 的根添加到 $QQ$，得到 $QQ(sqrt(2))$；
2. 把多项式 $x^2 + 1$ 的根添加到 $QQ(sqrt(2))$，得到 $QQ(sqrt(2))(i)$。

$QQ(sqrt(2), i) := QQ(sqrt(2))(i)$ 中的元素具有形式

$alpha + beta i$（$alpha, beta in QQ(sqrt(2))$）$= (a + b sqrt(2)) + (c + d sqrt(2)) i = a + b sqrt(2) + c i + d sqrt(2) i$，其中 $a, b, c, d in QQ$。

我们说 ${1, sqrt(2), i, sqrt(2) i}$ 是扩张 $QQ(sqrt(2), i)$ 在 $QQ$ 上的一组 *基*。因此，

$QQ(sqrt(2), i) = {a + b sqrt(2) + c i + d sqrt(2) i : a, b, c, d in QQ}$。

总之，$QQ(sqrt(2), i)$ 是从 $QQ$ 出发，添加 $h(x) = (x^2 - 2)(x^2 + 1) = x^4 - x^2 - 2$ 的全部根而构造出来的。它是 $h(x)$ 的分裂域。

%%% PAGE 8
== $QQ(sqrt(2), sqrt(3))$：$QQ$ 的另一个扩张域

### 问题
同时含有 $sqrt(2)$ 与 $sqrt(3)$ 的、$QQ$ 的最小扩张域 $F$ 是什么？

这一次，我们的域是 $QQ(sqrt(2), sqrt(3))$，从 $QQ$ 出发，添加多项式 $h(x) = (x^2 - 2)(x^2 - 3) = x^4 - 5 x^2 + 6$ 的全部根而构造。

不难证明 ${1, sqrt(2), sqrt(3), sqrt(6)}$ 是这个域的一组基，即

$QQ(sqrt(2), sqrt(3)) = {a + b sqrt(2) + c sqrt(3) + d sqrt(6) : a, b, c, d in QQ}$。

就像我们对一个群及其子群所做的那样，我们可以把 $QQ(sqrt(2), sqrt(3))$ 的子域排成一张格。我给每个扩张标上了需要添加其根的那个多项式的次数（见原图：顶为 $QQ(sqrt(2), sqrt(3))$，中间为 $QQ(sqrt(2))$、$QQ(sqrt(6))$、$QQ(sqrt(3))$，底为 $QQ$，各边次数为 2）。

只是为了好玩：哪个群的子群格看起来像这样？

%%% PAGE 9
== 域自同构

回想：群 $G$ 的自同构是一个同构 $phi : G -> G$。

### 定义
设 $F$ 是一个域。$F$ 的一个 *域自同构* 是一个双射 $phi : F -> F$，使得对所有 $a, b in F$，

$phi(a + b) = phi(a) + phi(b)$，并且 $phi(a b) = phi(a) phi(b)$。

换句话说，$phi$ 必须保持域的结构。

例如，令 $F = QQ(sqrt(2))$。请验证（家庭作业）函数

$phi : QQ(sqrt(2)) -> QQ(sqrt(2))$，$phi : a + b sqrt(2) |-> a - b sqrt(2)$

是一个自同构。也就是证明它保持加法与乘法。

$QQ(sqrt(2))$ 还有哪些其他的域自同构？

%%% PAGE 10
== 域自同构的一条决定性性质

域自同构是伽罗瓦理论的核心！我们很快就会看到为什么。

### 命题
若 $phi$ 是 $QQ$ 的一个扩张域 $F$ 的自同构，则对所有 $q in QQ$，都有 $phi(q) = q$。

### 证明
假设 $phi(1) = q$。显然 $q eq.not 0$。（为什么？）观察

$q = phi(1) = phi(1 dot 1) = phi(1) phi(1) = q^2$。

类似地，$q = phi(1) = phi(1 dot 1 dot 1) = q^3$，等等。由此，对每个 $n >= 1$ 都有 $q^n = q$。因此 $q = 1$。（由此可进一步推出 $phi$ 固定全部有理数。）证毕。

### 推论
$sqrt(2)$ 是无理数。证毕。

%%% PAGE 11
== 域扩张的伽罗瓦群

一个域的全部自同构在复合下构成一个群。

### 定义
设 $F$ 是 $QQ$ 的一个扩张域。$F$ 的 *伽罗瓦群* 是 $F$ 的自同构群，记作 $"Gal"(F)$。

这里有一些例子（不加证明）：

- $QQ(sqrt(2))$ 的伽罗瓦群是 $C_2$：$"Gal"(QQ(sqrt(2))) = angle.l f angle.r tilde.eq C_2$，其中 $f : sqrt(2) |-> -sqrt(2)$。
- $F = QQ(sqrt(2), i)$ 的一个自同构完全由它把 $sqrt(2)$ 与 $i$ 送到何处所确定。有四种可能：恒等映射 $e$，以及把 $sqrt(2)$、$i$ 分别送到 $plus.minus sqrt(2)$、$plus.minus i$ 的那些映射 $h$、$v$、$r$（见原图）。
- 因此，$F$ 的伽罗瓦群是 $"Gal"(QQ(sqrt(2), i)) = angle.l h, v angle.r tilde.eq V_4$。

== $QQ(zeta, root(3, 2))$：$QQ$ 的另一个扩张域

### 问题
含有 $g(x) = x^3 - 2$ 的全部根的、$QQ$ 的最小扩张域 $F$ 是什么？

令 $zeta = e^(2 pi i \/ 3) = -1\/2 + (sqrt(3)\/2) i$。这是一个 3 次单位根；$x^3 - 1 = (x - 1)(x^2 + x + 1)$ 的根是 $1$、$zeta$、$zeta^2$。

注意 $g(x)$ 的根是 $z_1 = root(3, 2)$，$z_2 = zeta root(3, 2)$，$z_3 = zeta^2 root(3, 2)$。

因此，我们要找的域是 $F = QQ(z_1, z_2, z_3)$。我断言 $F = QQ(zeta, root(3, 2))$。注意这个域含有 $z_1$、$z_2$ 与 $z_3$。反过来，我们可以用算术从 $z_1$ 与 $z_2$ 构造出 $zeta$ 与 $root(3, 2)$。

稍作代数运算可以证明

$QQ(zeta, root(3, 2)) = {a + b root(3, 2) + c root(3, 4) + d zeta + e zeta root(3, 2) + f zeta root(3, 4) : a, dots, f in QQ}$。

由于 $zeta = -1\/2 + (sqrt(3)\/2) i$ 落在 $QQ(zeta, root(3, 2))$ 中，所以 $2(zeta + 1\/2) = sqrt(3) i$ 也在其中。因此 $QQ(zeta, root(3, 2)) = QQ(sqrt(-3), root(3, 2)) = QQ(sqrt(3) i, root(3, 2))$。

== 到目前为止的小结

粗略地说，域是在加法与乘法（若排除 0）下都成群的集合，并用分配律把这两种运算连接起来。

我们主要关心域 $QQ$，以及某些扩张域 $F supset.eq QQ$。我们遇到过的一些扩张域：

$QQ(sqrt(2))$，$QQ(i)$，$QQ(sqrt(2), i)$，$QQ(sqrt(2), sqrt(3))$，$QQ(zeta, root(3, 2))$。

$F supset QQ$ 的一个自同构是保持结构并固定 $QQ$ 的映射。

$F supset.eq QQ$ 的全部自同构构成一个群，称为 $F$ 的伽罗瓦群，记作 $"Gal"(F)$。

$F$ 的子域与 $"Gal"(F)$ 的子群之间有一种引人入胜却又神秘的联系。这正是伽罗瓦理论的核心！

== 多项式

### 定义
设 $x$ 是一个未知变量。*多项式* 是函数

$f(x) = a_n x^n + a_(n-1) x^(n-1) + dots.c + a_2 x^2 + a_1 x + a_0$。

最高的非零次幂称为 $f$ 的 *次数*。

我们可以假定所有系数 $a_i$ 都落在某个域 $F$ 中。

例如，即使每个 $a_i in ZZ$（不是域），我们也可以改口说 $a_i in QQ$。

令 $F[x]$ 表示系数在 $F$ 中的多项式的集合。我们称之为 $F$ 上的多项式集合。

### 注记
即使 $ZZ$ 不是域，我们仍可以写 $ZZ[x]$ 表示整系数多项式的集合。我们遇到的大多数多项式反正都有整系数。

== 根式

低次多项式的根可以用算术与根式来表达。

例如，多项式 $f(x) = 5 x^4 - 18 x^2 - 27$ 的根是（见原公式，含二次根式的嵌套）。

### 注记
算术运算与根式，实际上是我们写下一般复数的“唯一办法”。

因此，若有某个数不能用根式表达，我们就没有办法表达它，除非为它发明一个特殊符号（例如 $pi$ 或 $e$）。

更奇怪的是：由于计算机程序不过是 0 与 1 的字符串，可能的程序只有可数无穷多个。

由于 $RR$ 是不可数集，有一些数（事实上是“几乎所有”的数）永远不能被计算机程序以算法的方式表达出来！这样的数称为“不可计算的”。

%%% PAGE 17
== 代数数

### 定义
一个复数是（在 $QQ$ 上）*代数的*，如果它是 $ZZ[x]$ 中某个多项式的根。全体代数数的集合 $A$ 构成一个域（这一点并非一目了然）。

在 $QQ$ 上不是代数的数（例如 $pi$、$e$）称为 *超越数*。

每一个能从自然数出发、用算术与根式表达出来的数都是代数的。例如，考虑 $x = root(5, 1 + sqrt(-3))$，经过化简可得它满足 $x^(10) - 2 x^5 + 4 = 0$。（幻灯片中间一步写为 $(x^5 - 1)^2 = -3$，应为 $(x^5 - 1)^2 = -3$ 经符号整理后得到该十次方程；以原图为准。）

### 问题
是否所有代数数都可以用根式表达？

这个问题直到 19 世纪初才得到解决。

== 关于复数的一些基本事实

### 定义
一个域 $F$ 是 *代数闭的*，如果对任意多项式 $f(x) in F[x]$，$f(x)$ 的全部根都落在 $F$ 中。

### 反例
- $QQ$ 不是代数闭的，因为 $f(x) = x^2 - 2 in QQ[x]$ 有一个根 $sqrt(2) in.not QQ$。
- $RR$ 不是代数闭的，因为 $f(x) = x^2 + 1 in RR[x]$ 有一个根 $sqrt(-1) in.not RR$。

### 代数基本定理
域 $CC$ 是代数闭的。

因此，每一个多项式 $f(x) in ZZ[x]$ 在 $CC$ 上完全分解，或者说 *分裂*：

$f(x) = (x - r_1)(x - r_2) dots.c (x - r_n)$，其中 $r_i in CC$。

反过来，若 $F$ 不是代数闭的，则存在多项式 $f(x) in F[x]$，它们在 $F$ 上不能分裂成一次因式。

== 不可约性

### 定义
多项式 $f(x) in F[x]$ 在 $F$ 上是 *可约的*，如果我们能把它分解为 $f(x) = g(x) h(x)$，其中 $g(x), h(x) in F[x]$ 的次数严格更低。若 $f(x)$ 不是可约的，就说它在 $F$ 上是 *不可约的*。

### 例子
- $x^2 - x - 6 = (x + 2)(x - 3)$ 在 $QQ$ 上可约。
- $x^4 + 5 x^2 + 4 = (x^2 + 1)(x^2 + 4)$ 在 $QQ$ 上可约，但它在 $QQ$ 中没有根。
- $x^3 - 2$ 在 $QQ$ 上不可约。若我们能分解它，则其中一个因式次数为 1。但 $x^3 - 2$ 在 $QQ$ 中没有根。

### 事实
- 若 $deg(f) > 1$ 且 $f$ 在 $F$ 中有一个根，则它在 $F$ 上可约。
- $ZZ[x]$ 中的每一个多项式在 $CC$ 上都可约。
- 若 $f(x) in F[x]$ 是 2 次或 3 次多项式，则 $f(x)$ 在 $F$ 上可约当且仅当 $f(x)$ 在 $F$ 中有一个根。

%%% PAGE 22
== 艾森斯坦不可约判别法

### 引理
设 $f in ZZ[x]$ 不可约。则 $f$ 在 $QQ$ 上也不可约。

等价地，若 $f in ZZ[x]$ 在 $QQ$ 上分解，则它在 $ZZ$ 上分解。

### 定理（艾森斯坦判别法）
多项式 $f(x) = a_n x^n + a_(n-1) x^(n-1) + dots.c + a_1 x + a_0 in ZZ[x]$ 是不可约的，如果对某个素数 $p$，下列条件全部成立：

1. $p$ 不整除 $a_n$；
2. $p$ 整除 $a_k$（对 $k = 0, dots, n-1$）；
3. $p^2$ 不整除 $a_0$。

例如，艾森斯坦判别法告诉我们 $x^(10) + 4 x^7 + 18 x + 14$ 不可约。

### 注记
若对所有素数 $p$，艾森斯坦判别法都失败，这并不一定意味着 $f$ 可约。例如，$f(x) = x^2 + x + 1$ 在 $QQ$ 上不可约，但艾森斯坦判别法检测不到这一点。

== 作为向量空间的扩张域

回想：$QQ$ 上的向量空间是一组向量 $V$，使得

- 若 $u, v in V$，则 $u + v in V$（对加法封闭）；
- 若 $v in V$，则对所有 $c in QQ$ 有 $c v in V$（对纯量乘法封闭）。

域 $QQ(sqrt(2))$ 是 $QQ$ 上的 2 维向量空间：$QQ(sqrt(2)) = {a + b sqrt(2) : a, b in QQ}$。这就是为什么我们说 ${1, sqrt(2)}$ 是 $QQ(sqrt(2))$ 在 $QQ$ 上的一组基。

注意，我们见过的其他域扩张也是 $QQ$ 上的向量空间：

- $QQ(sqrt(2), i) = {a + b sqrt(2) + c i + d sqrt(2) i : a, b, c, d in QQ}$；
- $QQ(zeta, root(3, 2)) = {a + b root(3, 2) + c root(3, 4) + d zeta + e zeta root(3, 2) + f zeta root(3, 4) : a, dots, f in QQ}$。

作为 $QQ$-向量空间，$QQ(sqrt(2), i)$ 的维数是 4，而 $QQ(zeta, root(3, 2))$ 的维数是 6。

### 定义
若 $F subset.eq E$ 是域，则扩张的 *次数*，记作 $[E : F]$，是 $E$ 作为 $F$ 上向量空间的维数。等价地，这是用 $F$ 中的系数写出 $E$ 的一般元素时所含项的个数。

== 极小多项式

### 定义
设 $r in.not F$ 是代数的。$r$ 在 $F$ 上的 *极小多项式* 是 $F[x]$ 中以 $r$ 为根的那个不可约多项式。它在相差一个纯量倍数的意义下是唯一的。

### 例子
- $sqrt(2)$ 在 $QQ$ 上的极小多项式是 $x^2 - 2$，且 $[QQ(sqrt(2)) : QQ] = 2$。
- $i = sqrt(-1)$ 在 $QQ$ 上的极小多项式是 $x^2 + 1$，且 $[QQ(i) : QQ] = 2$。
- $zeta = e^(2 pi i \/ 3)$ 在 $QQ$ 上的极小多项式是 $x^2 + x + 1$，且 $[QQ(zeta) : QQ] = 2$。
- $root(3, 2)$ 在 $QQ$ 上的极小多项式是 $x^3 - 2$，且 $[QQ(root(3, 2)) : QQ] = 3$。

下列数在 $QQ$ 上的极小多项式是什么？$-sqrt(2)$、$-i$、$zeta^2$、$zeta root(3, 2)$、$zeta^2 root(3, 2)$。

### 次数定理
扩张 $QQ(r)$ 的次数等于 $r$ 的极小多项式的次数。

%%% PAGE 25
== 多项式的伽罗瓦群

### 定义
设 $f in ZZ[x]$ 是一个多项式，根为 $r_1, dots, r_n$。$f$ 的 *分裂域* 是域 $QQ(r_1, dots, r_n)$。

$f(x)$ 的分裂域 $F$ 有若干等价刻画：

- 含有 $f(x)$ 全部根的最小域；
- $f(x)$ 在其中分裂成一次因式的最小域：$f(x) = (x - r_1) dots.c (x - r_n) in F[x]$。

回想：$QQ$ 的扩张 $F supset.eq QQ$ 的伽罗瓦群是 $F$ 的自同构群，记作 $"Gal"(F)$。

### 定义
多项式 $f(x)$ 的 *伽罗瓦群* 是其分裂域的伽罗瓦群，记作 $"Gal"(f(x))$。

%%% PAGE 26
== 伽罗瓦群的几个例子

- 多项式 $x^2 - 2$ 在 $QQ(sqrt(2))$ 中分裂，因此 $"Gal"(x^2 - 2) = "Gal"(QQ(sqrt(2))) tilde.eq C_2$。
- 多项式 $x^2 + 1$ 在 $QQ(i)$ 中分裂，因此 $"Gal"(x^2 + 1) = "Gal"(QQ(i)) tilde.eq C_2$。
- 多项式 $x^2 + x + 1$ 在 $QQ(zeta)$ 中分裂，其中 $zeta = e^(2 pi i \/ 3)$，因此 $"Gal"(x^2 + x + 1) = "Gal"(QQ(zeta)) tilde.eq C_2$。
- 多项式 $x^3 - 1 = (x - 1)(x^2 + x + 1)$ 也在 $QQ(zeta)$ 中分裂，因此 $"Gal"(x^3 - 1) = "Gal"(QQ(zeta)) tilde.eq C_2$。
- 多项式 $x^4 - x^2 - 2 = (x^2 - 2)(x^2 + 1)$ 在 $QQ(sqrt(2), i)$ 中分裂，因此 $"Gal"(x^4 - x^2 - 2) = "Gal"(QQ(sqrt(2), i)) tilde.eq V_4$。
- 多项式 $x^4 - 5 x^2 + 6 = (x^2 - 2)(x^2 - 3)$ 在 $QQ(sqrt(2), sqrt(3))$ 中分裂，因此 $"Gal"(x^4 - 5 x^2 + 6) = "Gal"(QQ(sqrt(2), sqrt(3))) tilde.eq V_4$。
- 多项式 $x^3 - 2$ 在 $QQ(zeta, root(3, 2))$ 中分裂，因此 $"Gal"(x^3 - 2) = "Gal"(QQ(zeta, root(3, 2))) tilde.eq D_3$？？？

%%% PAGE 27
== 域扩张的塔定律

回想：若有一条子群链 $K lt.eq H lt.eq G$，则指数满足塔定律：$[G : K] = [G : H][H : K]$。

并不奇怪，域扩张的次数服从类似的塔定律：

### 定理（塔定律）
对任意域扩张链 $F subset E subset K$，有 $[K : F] = [K : E][E : F]$。

我们在子域格中已经观察到这一点：

$[QQ(sqrt(2), sqrt(3)) : QQ] = [QQ(sqrt(2), sqrt(3)) : QQ(sqrt(2))] [QQ(sqrt(2)) : QQ] = 2 dot 2 = 4$（极小多项式分别为 $x^2 - 3$ 与 $x^2 - 2$）。

再举一例：$[QQ(zeta, root(3, 2)) : QQ] = [QQ(zeta, root(3, 2)) : QQ(root(3, 2))] [QQ(root(3, 2)) : QQ] = 2 dot 3 = 6$（极小多项式分别为 $x^2 + x + 1$ 与 $x^3 - 2$）。

== 本原元素

### 本原元素定理
若 $F$ 是 $QQ$ 的扩张且 $[F : QQ] < infinity$，则 $F$ 有一个 *本原元素*：某个 $alpha in.not QQ$，使得 $F = QQ(alpha)$。

如何找到 $F = QQ(zeta, root(3, 2)) = QQ(i sqrt(3), root(3, 2))$ 的一个本原元素 $alpha$？

试试 $alpha = i sqrt(3)\, root(3, 2) in F$。显然 $[QQ(alpha) : QQ] lt.eq 6$。计算各次幂后可见 $alpha$ 是 $x^6 + 108$ 的根。下列条件等价（为什么？）：

1. $alpha$ 是 $F$ 的本原元素；
2. $[QQ(alpha) : QQ] = 6$；
3. $alpha$ 的极小多项式 $m(x)$ 次数为 6；
4. $x^6 + 108$ 不可约（从而必是 $m(x)$）。

事实上 $[QQ(alpha) : QQ] = 6$ 成立，因为 2 与 3 都整除 $[QQ(alpha) : QQ]$：塔定律分别经过 $QQ(i sqrt(3))$（次数 2）与 $QQ(root(3, 2))$（次数 3）。

== 伽罗瓦群作用在根上

### 定理
若 $f in ZZ[x]$ 是一个多项式，且在 $QQ$ 的某个域扩张 $F$ 中有一个根，则 $F$ 的任一自同构都置换 $f$ 的根。

换一种说法，我们有一个 $"Gal"(f(x))$ 在 $f(x)$ 的根集 $S = {r_1, dots, r_n}$ 上的群作用。

也就是说，我们有一个同态 $psi : "Gal"(f(x)) -> "Perm"({r_1, dots, r_n})$。

若 $phi in "Gal"(f(x))$，则 $psi(phi)$ 是 $f(x)$ 的根的一个置换。

这个置换就是“按下 $phi$-按钮”的结果——它通过分裂域的自同构 $phi$ 来置换 $f(x)$ 的根。

### 推论
若 $f in ZZ[x]$ 的次数是 $n$，则 $f$ 的伽罗瓦群是 $S_n$ 的一个子群。

%%% PAGE 32
== 伽罗瓦群作用在根上（续）

下一条结果说的是：“$QQ$ 分不清一个不可约多项式的各个根。”

### “单轨道定理”
设 $r_1$ 与 $r_2$ 是 $QQ$ 上某个不可约多项式的根。则

(a) 存在一个同构 $phi : QQ(r_1) -> QQ(r_2)$，它固定 $QQ$ 并且满足 $phi(r_1) = r_2$。

(b) 当把 $QQ$ 替换为任意扩张域 $F$（其中 $QQ subset F subset CC$）时，这一点仍然成立。

### 推论
若 $f(x)$ 在 $QQ$ 上不可约，则对 $f(x)$ 的任意两个根 $r_1$ 与 $r_2$，伽罗瓦群 $"Gal"(f(x))$ 含有一个自同构 $phi : r_1 |-> r_2$。

换句话说，若 $f(x)$ 不可约，则 $"Gal"(f(x))$ 在根集 $S = {r_1, dots, r_n}$ 上的作用只有一个轨道。

%%% PAGE 33
== 正规域扩张

### 定义
$F$ 的一个扩张域 $E$ 是 *正规的*，如果它是某个多项式 $f(x)$ 的分裂域。

若 $E$ 是 $F$ 上的正规扩张，则 $F[x]$ 中每一个在 $E$ 中有一个根的不可约多项式，都在 $E$ 上分裂。（原文写“splits over $F$”，按标准陈述应为在 $E$ 上分裂。）

因此，若你能找到一个不可约多项式，它在 $E$ 中有一个根、但并非全部根，则 $E$ 不是正规扩张。

### 正规扩张定理
正规扩张的次数等于其伽罗瓦群的阶。

### 推论
多项式 $f(x)$ 的伽罗瓦群的阶，等于其分裂域在 $QQ$ 上的扩张次数。

%%% PAGE 34
== 正规域扩张：例子

考虑 $QQ(zeta, root(3, 2)) = QQ(alpha)$，它是 $f(x) = x^3 - 2$ 的分裂域。它也是 $m(x) = x^6 + 108$ 的分裂域，而这是 $alpha = root(3, 2) sqrt(-3)$ 的极小多项式。让我们看看它的哪些中间子域是 $QQ$ 的正规扩张。

- $QQ$：平凡地正规。
- $QQ(zeta)$：$x^2 + x + 1$ 的分裂域；根 $zeta$、$zeta^2 in QQ(zeta)$。正规。
- $QQ(root(3, 2))$：只含有 $x^3 - 2$ 的一个根，不含另外两个。不正规。
- $QQ(zeta root(3, 2))$：只含有 $x^3 - 2$ 的一个根，不含另外两个。不正规。
- $QQ(zeta^2 root(3, 2))$：只含有 $x^3 - 2$ 的一个根，不含另外两个。不正规。
- $QQ(zeta, root(3, 2))$：$x^3 - 2$ 的分裂域。正规。

由正规扩张定理，$|"Gal"(QQ(zeta))| = [QQ(zeta) : QQ] = 2$，且 $|"Gal"(QQ(zeta, root(3, 2)))| = [QQ(zeta, root(3, 2)) : QQ] = 6$。此外可以验证 $|"Gal"(QQ(root(3, 2)))| = 1 < [QQ(root(3, 2)) : QQ] = 3$。

我们现在可以确定性地给出 $x^3 - 2$ 的伽罗瓦群。

== 可解性

### 定义
一个群 $G$ 是 *可解的*，如果它有一条子群链

${e} = N_0 lt.tri.eq N_1 lt.tri.eq N_2 lt.tri.eq dots.c lt.tri.eq N_(k-1) lt.tri.eq N_k = G$，

使得每个商 $N_i \/ N_(i-1)$ 都是阿贝尔的。

注意：每个子群 $N_i$ 不必在 $G$ 中正规，只需在 $N_(i+1)$ 中正规。

### 例子
- $D_4 = angle.l r, f angle.r$ 可解。有许多可能的链，例如 $angle.l e angle.r lt.tri.eq angle.l f angle.r lt.tri.eq angle.l r^2, f angle.r lt.tri.eq D_4$，或 $angle.l e angle.r lt.tri.eq angle.l r angle.r lt.tri.eq D_4$，或 $angle.l e angle.r lt.tri.eq angle.l r^2 angle.r lt.tri.eq D_4$。
- 任意阿贝尔群 $A$ 都可解：取 $N_0 = {e}$ 且 $N_1 = A$。
- 对 $n >= 5$，群 $A_n$ 是单纯的且非阿贝尔的。因此唯一的正规子群链是 $N_0 = {e} lt.tri.eq A_n = N_1$。由于 $N_1 \/ N_0 tilde.eq A_n$ 非阿贝尔，$A_n$ 对 $n >= 5$ 不可解。

== 寻找一个不可解的多项式

下面的引理由对应定理推出。（为什么？）

### 引理
若 $N lt.tri.eq G$，则 $G$ 可解当且仅当 $N$ 与 $G \/ N$ 都可解。

### 推论
对所有 $n >= 5$，$S_n$ 不可解。（因为 $A_n lt.tri.eq S_n$ 不可解。）

### 伽罗瓦定理
域扩张 $E supset QQ$ 只含可用根式表达的元素，当且仅当它的伽罗瓦群可解。

### 推论
$f(x)$ 可用根式求解，当且仅当它有一个可解的伽罗瓦群。

因此，任何伽罗瓦群为 $S_5$ 的多项式都不可用根式求解！

%%% PAGE 42
== 一个不可解的五次多项式！

为了找到一个不可用根式求解的多项式，我们将寻找一个满足 $"Gal"(f(x)) tilde.eq S_5$ 的多项式 $f(x)$。

我们将把搜索限制在 5 次多项式，因为对任意 5 次多项式 $f(x)$ 都有 $"Gal"(f(x)) lt.eq S_5$。

### 关键观察
回想：对任意 5-轮换 $sigma$ 与 2-轮换（＝对换）$tau$，有 $S_5 = angle.l sigma, tau angle.r$。而且，$S_5$ 中仅有的 5 阶元素是 5-轮换，例如 $sigma = (a med b med c med d med e)$。

令 $f(x) = x^5 + 10 x^4 - 2$。由艾森斯坦判别法（取 $p = 2$）它不可约。令 $F = QQ(r_1, dots, r_5)$ 为其分裂域。

基本微积分告诉我们，$f$ 恰好有 3 个实根。令 $r_1, r_2 = a plus.minus b i$ 为复根，$r_3$、$r_4$ 与 $r_5$ 为实根。

由于 $f$ 有互异的复共轭根，复共轭是一个自同构 $tau : F -> F$，它把 $r_1$ 与 $r_2$ 对换，并固定三个实根。

%%% PAGE 43
== 一个不可解的五次多项式！（续）

我们刚刚找到了对换 $tau = (r_1 med r_2)$。剩下的只是找到一个 5 阶元素（即自同构）$sigma$。

取 $f(x)$ 的任意根 $r_i$。由于 $f(x)$ 不可约，它是 $r_i$ 的极小多项式。由次数定理，$[QQ(r_i) : QQ] = deg f(x) = 5$。

$f(x)$ 的分裂域是 $F = QQ(r_1, dots, r_5)$，由正规扩张定理，这个扩张在 $QQ$ 上的次数等于伽罗瓦群 $"Gal"(f(x))$ 的阶。

对此应用塔定律得 $|"Gal"(f(x))| = [F : QQ] = [F : QQ(r_1)] [QQ(r_1) : QQ]$，而后者等于 5。因此 $|"Gal"(f(x))|$ 是 5 的倍数，于是柯西定理保证 $G$ 有一个 5 阶元素 $sigma$。

由于 $"Gal"(f(x))$ 有一个 2-轮换 $tau$ 和一个 5-轮换 $sigma$，它必须是整个 $S_5$。

$"Gal"(f(x))$ 是一个不可解群，因此 $f(x) = x^5 + 10 x^4 - 2$ 不可用根式求解！

== 伽罗瓦工作的小结

设 $f(x)$ 是 $ZZ[x]$（或 $QQ[x]$）中的一个 $n$ 次多项式。$f(x)$ 的根落在某个分裂域 $F supset.eq QQ$ 中。

$f(x)$ 的伽罗瓦群是 $F$ 的自同构群。每一个这样的自同构都固定 $QQ$，并置换 $f(x)$ 的根。

这是 $"Gal"(f(x))$ 在 $n$ 个根的集合上的一个群作用！因此 $"Gal"(f(x)) lt.eq S_n$。

$F$ 的子域与 $"Gal"(f(x))$ 的子群之间有一一对应。

一个多项式可用根式求解，当且仅当它的伽罗瓦群是可解群。

对称群 $S_5$ 不是可解群。

由于对一个 2-轮换 $tau$ 和一个 5-轮换 $sigma$ 有 $S_5 = angle.l tau, sigma angle.r$，我们只需要找到一个 5 次多项式，其伽罗瓦群含有一个 2-轮换和一个 5 阶元素。

若 $f(x)$ 是一个有 3 个实根的不可约 5 次多项式，则复共轭是一个对换两个复根的自同构。此外，柯西定理告诉我们 $"Gal"(f(x))$ 必须有一个 5 阶元素。

因此，$f(x) = x^5 + 10 x^4 - 2$ 不可用根式求解！

== 几何与古希腊人

柏拉图（公元前 5 世纪）认为，唯一“完美”的几何图形是直线与圆。

在古希腊几何中，这一哲学意味着进行几何作图时只有两种工具可用：

1. 直尺：一条没有刻度的直边。
2. 圆规：从纸上提起时会闭合。

形式上，这意味着唯一被允许的作图，是欧几里得前三条公设所允许的那些。

%%% PAGE 46
== 几何与古希腊人（续）

大约公元前 300 年，古希腊数学家欧几里得写下了名为《几何原本》（The Elements）的十三卷书。

它是定义、公设（公理）以及定理与证明的汇集，涵盖几何、初等数论，以及希腊人的“几何代数”。

第 1 卷包含欧几里得著名的十条公设，以及其他基本的几何命题。

### 欧几里得前三条公设
1. 可以过任意两点作一条直线段。
2. 任意直线段可以沿直线无限延长。
3. 给定任意直线段，可以以该线段为半径、以其中一个端点为圆心作圆。

只用这些工具，线段可以被等分，角可以被平分，可以作平行线，$n$ 边形可以被“化方”，等等。

%%% PAGE 47
== 几何与古希腊人（续）

希腊数学的主要目的之一，是只使用直尺与圆规这两种基本工具，找出各种长度的精确作法。

古希腊人未能找到下列问题的作法：

### 问题 1：化圆为方
作一个与给定圆面积相同的正方形。

### 问题 2：倍立方
作一个体积为给定立方体两倍的立方体。

### 问题 3：三等分角
把一个角分成三个同样大小的更小的角。

两千多年来，这些问题一直没有解决。

最终，在 1837 年，Pierre Wantzel 用域理论证明了这些作图是不可能的。

%%% PAGE 48
== “可作图”意味着什么？

假定 $P_0$ 是 $RR^2$（或等价地，复平面 $CC$）中的一个点集。

### 定义
任意两条不同直线或圆的交点，是 *一步可作* 的。
点 $r in RR^2$ 是从 $P_0$ *可作的*，如果存在 $RR^2$ 中的有限点列 $r_1, dots, r_n = r$，使得对每个 $i = 1, dots, n$，点 $r_i$ 从 $P_0 union {r_1, dots, r_(i-1)}$ 是一步可作的。

### 例子：平分一条线段
1. 从线段 $p_1 p_2$ 出发；
2. 作以 $p_1$ 为圆心、$p_1 p_2$ 为半径的圆；
3. 作以 $p_2$ 为圆心、$p_1 p_2$ 为半径的圆；
4. 令 $r_1$ 与 $r_2$ 为交点；
5. 作直线 $r_1 r_2$；
6. 令 $r_3$ 为 $p_1 p_2$ 与 $r_1 r_2$ 的交点。

%%% PAGE 49
== 平分一个角

### 例子：平分一个角
1. 从点 $A$ 处的一个角出发；
2. 作以 $A$ 为圆心的圆；
3. 令 $B$ 与 $C$ 为交点；
4. 作以 $B$ 为圆心、$B C$ 为半径的圆；
5. 作以 $C$ 为圆心、$B C$ 为半径的圆；
6. 令 $D$ 与 $E$ 为这两个圆的交点；
7. 过 $D E$ 作直线。

假设 $A$ 在复平面的原点。则 $B = r$，$C = r e^(i theta)$。平分一个角意味着我们可以从 $r e^(i theta)$ 作出 $r e^(i theta \/ 2)$。

%%% PAGE 50
== 可作数：实与复

此后，我们将说一个点是可作的，如果它是从集合 $P_0 = {(0, 0), (1, 0)} subset RR^2$ 可作的。

说 $z = x + y i in CC$ 是可作的，如果 $(x, y) in RR^2$ 是可作的。令 $K subset.eq CC$ 表示可作数。

### 引理
复数 $z = x + y i$ 是可作的，如果 $x$ 与 $y$ 是可作的。

由下面的引理，我们可以把注意力限制在实可作数上。

### 引理
1. $K inter RR$ 是 $RR$ 的子域，当且仅当 $K$ 是 $CC$ 的子域。
2. 此外，$K inter RR$ 对（非负）平方根封闭，当且仅当 $K$ 对（全部）平方根封闭。

$K inter RR$ 对平方根封闭意味着：$a in K inter RR^+$ 蕴涵 $sqrt(a) in K inter RR$。
$K$ 对平方根封闭意味着：$z = r e^(i theta) in K$ 蕴涵 $sqrt(z) = sqrt(r) e^(i theta \/ 2) in K$。

%%% PAGE 51
== 可作数域

### 定理
可作数的集合 $K$ 是 $CC$ 的一个子域，并且对取平方根与复共轭封闭。

### 证明（概要）
设 $a$ 与 $b$ 是可作实数，且 $a > 0$。不难验证下列各项都成立：

1. $-a$ 可作；
2. $a + b$ 可作；
3. $a b$ 可作；
4. $a^(-1)$ 可作；
5. $sqrt(a)$ 可作；
6. 若 $a + b i$ 可作，则 $a - b i$ 可作。

### 推论
若 $a, b, c in CC$ 可作，则 $a x^2 + b x + c$ 的根也可作。

%%% PAGE 52
== 作为域扩张的作图

设 $F subset K$ 是由尺规作图生成的一个域。假设 $alpha$ 从 $F$ 一步可作。我们希望确定 $[F(alpha) : F]$。

### 从 $F$ 构造新点的三种方式
1. 两条直线相交。$a x + b y = c$ 与 $d x + e y = f$ 的解落在 $F$ 中。
2. 圆与直线相交。方程组 $a x + b y = c$ 与 $(x - d)^2 + (y - e)^2 = r^2$ 的解落在 $F$ 的（至多）二次扩张中。
3. 两圆相交。需要解 $(x - a)^2 + (y - b)^2 = s^2$ 与 $(x - d)^2 + (y - e)^2 = r^2$。把它们展开并相减，$x^2$ 与 $y^2$ 项抵消，留下一条直线的方程。把这条直线与其中一个圆相交，就回到情形 2。

在所有这些情形中，$[F(alpha) : F] lt.eq 2$。

%%% PAGE 53
== 作为域扩张的作图（续）

换句话说，一步作出一个 $alpha in.not F$ 的数，相当于取 $F$ 的一个 2 次扩张。

### 定理
一个复数 $alpha$ 是可作的，当且仅当存在一条域扩张塔

$QQ = K_0 subset K_1 subset dots.c subset K_n subset CC$，

其中 $alpha in K_n$，且对每个 $i$ 有 $[K_(i+1) : K_i] lt.eq 2$。

### 推论
可作数的集合 $K subset CC$ 是一个域。而且，若 $alpha in K$，则 $[QQ(alpha) : QQ] = 2^n$，对某个整数 $n$。

接下来，我们将证明古希腊人的经典作图问题是不可能的，方法是说明每一个都会产生一个 $alpha in RR$，使得 $[QQ(alpha) : QQ]$ 不是 2 的幂。

%%% PAGE 54
== 重新表述的经典作图问题

### 问题 1：化圆为方
给定半径为 $r$（从而面积为 $pi r^2$）的圆，作一个面积为 $pi r^2$（从而边长为 $sqrt(pi) r$）的正方形。

若能化圆为方，则 $sqrt(pi) in K subset CC$，即可作数域。然而 $QQ subset QQ(pi) subset QQ(sqrt(pi))$，因此 $[QQ(sqrt(pi)) : QQ] >= [QQ(pi) : QQ] = infinity$。故 $pi$ 不可作。

### 问题 2：倍立方
给定边长为 $ell$（从而体积为 $ell^3$）的立方体，作一个体积为 $2 ell^3$（从而边长为 $root(3, 2) ell$）的立方体。

若能倍立方，则 $root(3, 2) in K$。然而 $[QQ(root(3, 2)) : QQ] = 3$ 不是 2 的幂。故 $root(3, 2)$ 不可作。

%%% PAGE 55
== 重新表述的经典作图问题（续）

### 问题 3：三等分角
给定 $e^(i theta)$，作出 $e^(i theta \/ 3)$。或者等价地，从 $cos(theta)$ 作出 $cos(theta \/ 3)$。

我们将证明 $theta = 60 degree$ 不能被三等分。换句话说，$alpha = cos(20 degree)$ 不能从 $cos(60 degree)$ 作出。

三倍角公式给出 $cos(theta) = 4 cos^3 (theta \/ 3) - 3 cos(theta \/ 3)$。令 $theta = 60 degree$，代入 $cos(theta) = 1\/2$ 与 $alpha = cos(20 degree)$，得到 $4 alpha^3 - 3 alpha - 1\/2 = 0$。作变量替换 $u = 2 alpha$，再乘以 2，得 $u^3 - 3 u - 1 = 0$。

因此 $u$ 是（不可约的！）多项式 $x^3 - 3 x - 1$ 的根。于是 $[QQ(u) : QQ] = 3$，不是 2 的幂。

故 $u = 2 cos(20 degree)$ 不可作，从而 $alpha = cos(20 degree)$ 也不可作。

%%% PAGE 56
== 经典作图问题的解决

曾经难倒古希腊人的三个经典尺规作图问题，翻译成域理论的语言如下：

### 问题 1：化圆为方
从 1 作出 $sqrt(pi)$。

### 问题 2：倍立方
从 1 作出 $root(3, 2)$。

### 问题 3：三等分角
从 $cos(theta)$ 作出 $cos(theta \/ 3)$。[或者从 1 作出 $cos(20 degree)$。]

由于这些数都不落在 $QQ$ 的某个次数为 $2^n$ 的扩张中，它们都不可作。

如果允许使用“带刻度的直尺”，则这些作图变得可能，古希腊人已经知道这一点。

%%% PAGE 57
== 正多边形的作图

古希腊人也对作正多边形感兴趣。他们知道 3 边形、5 边形与 15 边形的作法。

1796 年，19 岁的 Carl Friedrich Gauß（高斯）——当时他还未决定是学数学还是学语言——发现了如何作正 17 边形。

高斯对自己的发现如此高兴，以至于把一生献给了数学。

他还证明了关于哪些 $n$ 边形可作的下列定理。

### 定理（Gauß，Wantzel）
设 $p$ 是奇素数。正 $p$ 边形可作，当且仅当对某个 $n >= 0$ 有 $p = 2^(2^n) + 1$。

下一个要问的问题是：对哪些 $n$，$2^(2^n) + 1$ 是素数？

%%% PAGE 58
== 正多边形的作图与费马素数

### 定义
第 $n$ 个 *费马数* 是 $F_n := 2^(2^n) + 1$。若 $F_n$ 是素数，则它是一个 *费马素数*。

最初几个费马素数是 $F_0 = 3$、$F_1 = 5$、$F_2 = 17$、$F_3 = 257$ 与 $F_4 = 65537$。

它们以 Pierre Fermat（1601–1665）命名，他在 17 世纪猜想所有费马数 $F_n = 2^(2^n) + 1$ 都是素数。

%%% PAGE 59
== 正多边形的作图与费马素数（续）

1732 年，Leonhard Euler（欧拉）通过证明 $F_5 = 2^(2^5) + 1 = 2^(32) + 1 = 4294967297 = 641 dot 6700417$ 否定了费马的猜想。

是否还存在其他费马素数，至今未知！

到目前为止，对 $5 lt.eq n lt.eq 32$，每一个 $F_n$ 都已知是合数。2014 年，一台计算机证明 $193 times 2^(3329782) + 1$ 是 $F_3329780 = 2^(2^3329780) + 1 > 10^(10^106)$ 的一个素因子。

### 定理（Gauß，Wantzel）
正 $n$ 边形可作，当且仅当 $n = 2^k p_1 dots.c p_m$，其中 $p_1, dots, p_m$ 是互异的费马素数。
