## 第 2 页 / 46

**什么是环？**

**定义**
*环* 是一个加法（阿贝尔）群 $R$，带有一个额外的二元运算（乘法），并满足分配律：

$x(y + z) = x y + x z$ 且 $(y + z)x = y x + z x$，对所有 $x, y, z in R$。

**注记**
- 不必有乘法逆元。
- 乘法不必交换（可能出现 $x y eq.not y x$）。

**再几个术语**
若对所有 $x, y in R$ 都有 $x y = y x$，则 $R$ 是 *交换的*。

若 $R$ 有乘法单位元 $1 = 1_R eq.not 0$，我们说“$R$ 有单位元”或“有幺元”，或“$R$ 是带 1 的环”。

$R$ 的一个 *子环* 是一个本身也是环的子集 $S subset.eq R$。

## 第 3 页 / 46

**什么是环？（续）**

**例子**
1. $ZZ subset QQ subset RR subset CC$ 都是带 1 的交换环。
2. $ZZ_n$ 是带 1 的交换环。
3. 对任意带 1 的环 $R$，$R$ 上 $n times n$ 矩阵的集合 $M_n (R)$ 是一个环。它有单位元 $1_(M_n (R)) = I_n$ 当且仅当 $R$ 有 1。
4. 对任意环 $R$，函数集 $F = {f : R -> R}$ 通过定义 $(f + g)(r) = f(r) + g(r)$、$(f g)(r) = f(r) g(r)$ 成为一个环。
5. 集合 $S = 2 ZZ$ 是 $ZZ$ 的子环，但它没有 1。
6. $S = {mat(a, 0; 0, 0) : a in RR}$ 是 $R = M_2 (RR)$ 的子环。然而注意 $1_R = mat(1, 0; 0, 1)$，但 $1_S = mat(1, 0; 0, 0)$。
7. 若 $R$ 是环且 $x$ 是变量，则集合 $R[x] = {a_n x^n + dots.c + a_1 x + a_0 mid(|) a_i in R}$ 称为 $R$ 上的 *多项式环*。

**单位与零因子**

**定义**
设 $R$ 是带 1 的环。*单位* 是任意有乘法逆元的 $x in R$。令 $U(R)$ 为 $R$ 的单位的集合（一个乘法群）。

元素 $x in R$ 是 *左零因子*，如果对某个 $y eq.not 0$ 有 $x y = 0$。（右零因子类似定义。）

**例子**
1. 令 $R = ZZ$。单位是 $U(R) = {-1, 1}$。没有（非零）零因子。
2. 令 $R = ZZ_10$。则 7 是单位（且 $7^(-1) = 3$），因为 $7 dot 3 = 1$。然而 2 不是单位。
3. 令 $R = ZZ_n$。非零的 $k in ZZ_n$ 是单位，如果 $gcd(n, k) = 1$；是零因子，如果 $gcd(n, k) >= 2$。
4. 环 $R = M_2 (RR)$ 有零因子，例如 $mat(1, -2; -2, 4) mat(6, 2; 3, 1) = mat(0, 0; 0, 0)$。$M_2 (RR)$ 的单位群是可逆矩阵。

## 第 6 页 / 46

**群环**

设 $R$ 是交换环（通常是 $ZZ$、$RR$ 或 $CC$），$G$ 是有限（乘法）群。我们可以定义 *群环* $R G$ 为

$R G := {a_1 g_1 + dots.c + a_n g_n mid(|) a_i in R, g_i in G}$，

乘法按“显然”的方式定义。

例如，令 $R = ZZ$ 且 $G = D_4 = angle.l r, f mid(|) r^4 = f^2 = r f r f = 1 angle.r$，考虑元素 $x = r + r^2 - 3 f$ 与 $y = -5 r^2 + r f$ 在 $ZZ D_4$ 中。它们的和是 $x + y = r - 4 r^2 - 3 f + r f$，乘积展开后为 $-5 - 8 r^3 + 16 r^2 f + r^3 f$（见原计算）。

**注记**
- （实）Hamiltonians $HH$ 与群环 $RR Q_8$ 不是同一个环。
- 若 $g in G$ 有有限阶 $|g| = k > 1$，则 $R G$ 总有零因子：$(1 - g)(1 + g + dots.c + g^(k-1)) = 1 - g^k = 0$。
- $R G$ 含有一个同构于 $R$ 的子环，并且单位群 $U(R G)$ 含有一个同构于 $G$ 的子群。

## 第 7 页 / 46

**环的类型**

**定义**
若 $R$ 的所有非零元素都有乘法逆元，则 $R$ 是一个 *除环*。（可以想成：“没有交换性的域”。）

*整环* 是带 1、且没有（非零）零因子的交换环。（可以想成：“没有逆元的域”。）

*域* 不过是交换的除环。而且：域 $subset$ 除环；域 $subset$ 整环 $subset$ 所有环。

**例子**
- 不是整环的环：$ZZ_n$（$n$ 为合数）、$2 ZZ$、$M_n (RR)$、$ZZ times ZZ$、$HH$。（$HH$ 无零因子，但不是交换的，因此不是整环。）
- 不是域（甚至不是除环）的整环：$ZZ$、$ZZ[x]$、$RR[x]$、$RR[[x]]$（形式幂级数）。
- 是除环但不是域：$HH$。

## 第 8 页 / 46

**消去律**

在做基本代数时，我们常常把消去律这样的基本性质视为理所当然：$a x = a y arrow.r.double x = y$。然而，这不必在所有环中成立！

**消去律失败的例子**
- 在 $ZZ_6$ 中，注意 $2 = 2 dot 1 = 2 dot 4$，但 $1 eq.not 4$。
- 在 $M_2 (RR)$ 中，同一个矩阵可以用两种不同的因式分解写出（见原图），从而消去律失败。

不过，只要没有（非零）零因子，一切都运作良好。

**命题**
设 $R$ 是整环且 $a eq.not 0$。若对某个 $x, y in R$ 有 $a x = a y$，则 $x = y$。

**证明**
若 $a x = a y$，则 $a x - a y = a(x - y) = 0$。由于 $a eq.not 0$ 且 $R$ 没有（非零）零因子，于是 $x - y = 0$。证毕。

## 第 9 页 / 46

**有限整环**

**引理（家庭作业）**
若 $R$ 是整环且 $0 eq.not a in R$、$k in NN$，则 $a^k eq.not 0$。证毕。

**定理**
每一个有限整环都是域。

**证明**
假设 $R$ 是有限整环且 $0 eq.not a in R$。只需证明 $a$ 有乘法逆元。考虑无穷序列 $a, a^2, a^3, a^4, dots$，它必须重复。找出 $i > j$ 使得 $a^i = a^j$，这意味着 $0 = a^i - a^j = a^j (a^(i-j) - 1)$。由于 $R$ 是整环且 $a^j eq.not 0$，于是 $a^(i-j) = 1$。因此 $a dot a^(i-j-1) = 1$。证毕。

## 第 10 页 / 46

**理想**

在群论中，我们可以模掉一个子群，当且仅当它是正规子群。对环而言，与此类似的是（双边）理想。

**定义**
子环 $I subset.eq R$ 是一个 *左理想*，如果对所有 $r in R$ 与 $x in I$ 都有 $r x in I$。右理想与双边理想类似定义。

若 $R$ 是交换的，则所有左（或右）理想都是双边的。我们把“理想”与“双边理想”当作同义词使用，并写 $I lt.tri.eq R$。

**例子**
- $n ZZ lt.tri.eq ZZ$。
- 若 $R = M_2 (RR)$，则 $I = {mat(a, 0; c, 0) : a, c in RR}$ 是 $R$ 的左理想，但不是右理想。
- $n times n$ 对称矩阵的集合 $"Sym"_n (RR)$ 是 $M_n (RR)$ 的子环，但不是理想。

## 第 11 页 / 46

**理想（续）**

**注记**
若 $R$ 的一个理想 $I$ 含有 1，则 $I = R$。

**证明**
假设 $1 in I$，任取 $r in R$。则 $r dot 1 in I$，于是 $r in I$。因此 $I = R$。证毕。

不难把上述结果稍加修改，证明：若 $I$ 含有任何单位，则 $I = R$。（家庭作业）

让我们比较正规子群与理想的概念：

- 正规子群的特征是在共轭下不变：$H lt.eq G$ 正规，当且仅当对所有 $g in G$、$h in H$ 有 $g h g^(-1) in H$。
- 环的（左）理想的特征是在（左）乘法下不变：$I subset.eq R$ 是（左）理想，当且仅当对所有 $r in R$、$i in I$ 有 $r i in I$。

## 第 12 页 / 46

**由集合生成的理想**

**定义**
由集合 $X subset R$ 生成的左理想定义为：$(X) := inter {I : I "是左理想且" X subset.eq I subset.eq R}$。这是含有 $X$ 的最小左理想。把“左”换成“右”或“双边”，有类似定义。

回想由子集 $X subset.eq G$ 生成的子群 $angle.l X angle.r$ 的两种定义方式：

- “自下而上”：作为 $X$ 中元素的一切有限乘积的集合；
- “自上而下”：作为含有 $X$ 的所有子群的交。

**命题（家庭作业）**
设 $R$ 是带单位元的环。由 $X subset.eq R$ 生成的（左、右、双边）理想是：

- 左：${r_1 x_1 + dots.c + r_n x_n : n in NN, r_i in R, x_i in X}$；
- 右：${x_1 r_1 + dots.c + x_n r_n : n in NN, r_i in R, x_i in X}$；
- 双边：${r_1 x_1 s_1 + dots.c + r_n x_n s_n : n in NN, r_i, s_i in R, x_i in X}$。

## 第 13 页 / 46

**理想与商**

由于 $R$ 的理想 $I$ 是加法子群（从而正规），于是：

- $R \/ I = {x + I mid(|) x in R}$ 是 $I$ 在 $R$ 中的陪集的集合；
- $R \/ I$ 是一个商群；二元运算（加法）定义为 $(x + I) + (y + I) := x + y + I$。

事实证明，若 $I$ 还是双边理想，我们就可以把 $R \/ I$ 做成一个环。

**命题**
若 $I subset.eq R$ 是（双边）理想，则 $R \/ I$ 是一个环（称为 *商环*），其中乘法定义为 $(x + I)(y + I) := x y + I$。

**证明**
我们需要证明这是良定义的。假设 $x + I = r + I$ 且 $y + I = s + I$。这意味着 $x - r in I$ 且 $y - s in I$。只需证明 $x y + I = r s + I$，或等价地 $x y - r s in I$：$x y - r s = x y - r y + r y - r s = (x - r) y + r (y - s) in I$。

## 第 14 页 / 46

**有限域**

我们已经看到，若 $p$ 是素数则 $ZZ_p$ 是域，并且有限整环都是域。但这些“其他”的有限域长什么样？

令 $R = ZZ_2 [x]$ 为域 $ZZ_2$ 上的多项式环。（注意：我们可以忽略所有负号。）

多项式 $f(x) = x^2 + x + 1$ 在 $ZZ_2$ 上不可约，因为它没有根。（注意 $f(0) = f(1) = 1 eq.not 0$。）

考虑理想 $I = (x^2 + x + 1)$，即 $x^2 + x + 1$ 的倍数的集合。

在商环 $R \/ I$ 中，我们有关系 $x^2 + x + 1 = 0$，或等价地 $x^2 = -x - 1 = x + 1$。

这个商只有 4 个元素：$0 + I$、$1 + I$、$x + I$、$(x + 1) + I$。与商群（或商环）$ZZ \/ n ZZ$ 一样，我们通常去掉“$I$”，只写 $R \/ I = ZZ_2 [x] \/ (x^2 + x + 1) tilde.eq {0, 1, x, x + 1}$。不难验证这是一个域！

## 第 16 页 / 46

**动机（剧透！）**

群同态中的许多核心思想都可以带到环同态上。

**群论**
- 商群 $G \/ N$ 存在，当且仅当 $N$ 是正规子群。
- 同态是保持结构的映射：$f(x * y) = f(x) * f(y)$。
- 同态的核是正规子群：$ker phi lt.tri.eq G$。
- 对每一个正规子群 $N lt.tri.eq G$，有一个自然的商同态 $phi : G -> G \/ N$，$phi(g) = g N$。
- 群有四条标准同构定理。

**环论**
- 商环 $R \/ I$ 存在，当且仅当 $I$ 是双边理想。
- 同态是保持结构的映射：$f(x + y) = f(x) + f(y)$ 且 $f(x y) = f(x) f(y)$。
- 同态的核是双边理想：$ker phi lt.tri.eq R$。
- 对每一个双边理想 $I lt.tri.eq R$，有一个自然的商同态 $phi : R -> R \/ I$，$phi(r) = r + I$。
- 环有四条标准同构定理。

## 第 17 页 / 46

**环同态**

**定义**
*环同态* 是满足 $f(x + y) = f(x) + f(y)$ 且 $f(x y) = f(x) f(y)$（对所有 $x, y in R$）的函数 $f : R -> S$。

*环同构* 是双射的同态。

$f : R -> S$ 的 *核* 是集合 $ker f := {x in R : f(x) = 0}$。

**例子**
1. 把 $k |-> k med (mod n)$ 的函数 $phi : ZZ -> ZZ_n$ 是一个环同态，且 $ker(phi) = n ZZ$。
2. 对固定的实数 $alpha in RR$，“赋值函数” $phi : RR[x] -> RR$，$phi : p(x) |-> p(alpha)$ 是一个同态。核由所有以 $alpha$ 为根的多项式组成。
3. 对 $ZZ_2 [x]$ 中的理想 $I = (x^2 + x + 1)$，下列是一个同态：$phi : ZZ_2 [x] -> ZZ_2 [x] \/ I$，$f(x) |-> f(x) + I$。

**环的同构定理**

**基本同态定理**
若 $phi : R -> S$ 是环同态，则 $ker phi$ 是理想，且 $"Im"(phi) tilde.eq R \/ ker(phi)$。

图示：$R$ 经任意同态 $phi$ 映到 $"Im" phi lt.eq S$；经商过程 $q$ 到达商环 $R \/ ker phi$，再经剩余的同构 $g$（“重新标记”）到达 $"Im" phi$。

**证明（家庭作业）**
该陈述对底加法群 $R$ 成立。因此，剩下要证明 $ker phi$ 是（双边）理想，并且下列映射是环同态：$g : R \/ I -> "Im" phi$，$g(x + I) = phi(x)$。

## 第 19 页 / 46

**环的第二同构定理**

假设 $S$ 是子环，$I$ 是 $R$ 的理想。则

(i) 和 $S + I = {s + i mid(|) s in S, i in I}$ 是 $R$ 的子环，并且交 $S inter I$ 是 $S$ 的理想。

(ii) 下列商环同构：$(S + I) \/ I tilde.eq S \/ (S inter I)$。

**证明（概要）**
$S + I$ 是加法子群，并且对乘法封闭，因为 $(s_1 + i_1)(s_2 + i_2) = s_1 s_2 + s_1 i_2 + i_1 s_2 + i_1 i_2 in S + I$（第一项在 $S$ 中，后三项在 $I$ 中）。证明 $S inter I$ 是 $S$ 的理想是直接的（家庭作业）。我们已经知道 $(S + I) \/ I tilde.eq S \/ (S inter I)$ 作为加法群。一个显式同构是 $phi : s + (S inter I) |-> s + I$。容易验证 $phi : 1 |-> 1$ 且 $phi$ 保持乘积。证毕。

## 第 22 页 / 46

**极大理想**

**定义**
$R$ 的理想 $I$ 是 *极大的*，如果 $I eq.not R$，并且若对某个理想 $J$ 有 $I subset.eq J subset.eq R$，则 $J = I$ 或 $J = R$。

环 $R$ 是 *单的*，如果它仅有的（双边）理想是 0 与 $R$。

**例子**
1. 若 $n eq.not 0$，则 $R = ZZ$ 的理想 $M = (n)$ 是极大的，当且仅当 $n$ 是素数。
2. 令 $R = QQ[x]$ 为 $QQ$ 上全部多项式的集合。由全部常数项为零的多项式组成的理想 $M = (x)$ 是极大理想。商环 $QQ[x] \/ (x)$ 中的元素具有形式 $f(x) + M = a_0 + M$。
3. 令 $R = ZZ_2 [x]$，即 $ZZ_2$ 上的多项式。理想 $M = (x^2 + x + 1)$ 是极大的，且 $R \/ M tilde.eq FF_4$，即（唯一的）4 阶有限域。

在以上三个例子中，商 $R \/ M$ 都是域。

## 第 23 页 / 46

**极大理想（续）**

**定理**
设 $R$ 是带 1 的交换环。对理想 $I subset.eq R$，下列条件等价：

(i) $I$ 是极大理想；

(ii) $R \/ I$ 是单的；

(iii) $R \/ I$ 是域。

**证明**
等价 (i) $arrow.l.r.double$ (ii) 由对应定理立即得到。对于 (ii) $arrow.l.r.double$ (iii)，我们将证明一个任意的环 $R$ 是单的当且仅当 $R$ 是域。

“$arrow.r.double$”：假设 $R$ 是单的。则对任意非零 $a in R$ 有 $(a) = R$。因此 $1 in (a)$，于是 $1 = b a$ 对某个 $b in R$，故 $a in U(R)$，$R$ 是域。

**整除与分解**

环在某种意义上是我们所熟悉的数系（如 $ZZ$、$RR$ 与 $CC$）的推广，在其中我们可以做加法、减法与乘法。

这些结构的两个关键性质是：乘法是交换的；没有（非零）零因子。

**贯穿约定**
在本讲中，除非另行明确说明，都假定 $R$ 是整环，并且我们定义 $R^ast := R without {0}$。

整数有若干我们通常视为理所当然的基本性质：

- 每一个非零数都可以唯一地分解成素数的乘积；
- 任意两个数有唯一的最大公因数与最小公倍数；
- 有欧几里得算法，可以求出两个数的最大公因数。

出人意料的是，这些不必在所有整环中都成立！我们希望更好地理解这一点。

## 第 26 页 / 46

**整除**

**定义**
若 $a, b in R$，说 * $a$ 整除 $b$ *，或 *$b$ 是 $a$ 的倍数*，如果对某个 $c in R$ 有 $b = a c$。我们写 $a mid b$。

若 $a mid b$ 且 $b mid a$，则 $a$ 与 $b$ 是 *相伴的*，记作 $a tilde b$。

**例子**
- 在 $ZZ$ 中：$n$ 与 $-n$ 相伴。
- 在 $RR[x]$ 中：$f(x)$ 与 $c dot f(x)$ 对任意 $c eq.not 0$ 相伴。
- 0 的唯一相伴元是它自己。
- 1 的相伴元是 $R$ 的单位。

**命题（家庭作业）**
两个元素 $a, b in R$ 相伴，当且仅当 $a = b u$ 对某个单位 $u in U(R)$。这在 $R$ 上定义了一个等价关系，并把 $R$ 划分成等价类。

## 第 27 页 / 46

**不可约元与素元**

注意单位整除一切：若 $b in R$ 且 $u in U(R)$，则 $u mid b$。

**定义**
若 $b in R$ 不是单位，并且 $b$ 仅有的因子是单位以及 $b$ 的相伴元，则 $b$ 是 *不可约的*。

元素 $p in R$ 是 *素的*，如果 $p$ 不是单位，并且 $p mid a b$ 蕴涵 $p mid a$ 或 $p mid b$。

**命题**
若 $0 eq.not p in R$ 是素的，则 $p$ 不可约。

**证明**
假设 $p$ 是素的但不是不可约的。则 $p = a b$，其中 $a, b in.not U(R)$。于是（不妨设）$p mid a$，故 $a = p c$ 对某个 $c in R$。现在 $p = a b = (p c) b = p (c b)$。这意味着 $c b = 1$，从而 $b in U(R)$，矛盾。证毕。

## 第 28 页 / 46

**不可约元与素元（续）**

**注意：不可约不必蕴涵素**

考虑环 $R_(-5) := {a + b sqrt(-5) : a, b in ZZ}$。有 $3 mid (2 + sqrt(-5))(2 - sqrt(-5)) = 9 = 3 dot 3$，但 $3$ 不整除 $2 + sqrt(-5)$，也不整除 $2 - sqrt(-5)$。因此，3 在 $R_(-5)$ 中不可约但不是素的。

当不可约元不再是素元时，我们可能失去像唯一分解这样的好性质。情况还可能更糟：连分解成不可约元的长度都不一定相同！

例如，考虑环 $R = ZZ[x^2, x^3]$。则 $x^6 = x^2 dot x^2 dot x^2 = x^3 dot x^3$。元素 $x^2 in R$ 不是素的，因为 $x^2 mid x^3 dot x^3$，但在 $R$ 中 $x^2$ 不整除 $x^3$（注意：$x in.not R$）。

## 第 29 页 / 46

**主理想整环**

幸运的是，有一类环不会发生这类“坏事”。

**定义**
由单个元素 $a in R$ 生成的理想 $I$ 称为 *主理想*。我们把它记作 $I = (a)$。

若 $R$ 的每一个理想都是主理想，则 $R$ 是一个 *主理想整环*（PID）。

**例子**
下列都是 PID（不加证明地陈述）：整数环 $ZZ$；任意域 $F$；域上的多项式环 $F[x]$。

我们很快会看到，PID 是“好”的环。它们享有的一些性质包括：元素对有“最大公因数”与“最小公倍数”；不可约蕴涵素；每一个元素都可以唯一地分解成素元的乘积。

## 第 30 页 / 46

**最大公因数与最小公倍数**

**命题**
若 $I subset.eq ZZ$ 是理想，且 $a in I$ 是其中最小的正元素，则 $I = (a)$。

**证明**
任取正的 $b in I$。写 $b = a q + r$，其中 $q, r in ZZ$ 且 $0 lt.eq r < a$。则 $r = b - a q in I$，故 $r = 0$。因此 $b = q a in (a)$。证毕。

**定义**
$a, b in R$ 的 *公因子* 是满足 $d mid a$ 且 $d mid b$ 的元素 $d in R$。而且，若对 $a$ 与 $b$ 的所有其他公因子 $c$ 都有 $c mid d$，则 $d$ 是 *最大公因数*（GCD）。

$a, b in R$ 的 *公倍数* 是满足 $a mid m$ 且 $b mid m$ 的元素 $m in R$。而且，若对 $a$ 与 $b$ 的所有其他公倍数 $n$ 都有 $m mid n$，则 $m$ 是 *最小公倍数*（LCM）。

## 第 31 页 / 46

**PID 的好性质**

**命题**
若 $R$ 是 PID，则任意 $a, b in R^ast$ 都有一个最大公因数 $d = gcd(a, b)$。它在相差相伴的意义下唯一，并且可以写成 $d = x a + y b$，对某个 $x, y in R$。

**证明**
存在性。由 $a$ 与 $b$ 生成的理想是 $I = (a, b) = {u a + v b : u, v in R}$。由于 $R$ 是 PID，我们可以写 $I = (d)$ 对某个 $d in I$，于是 $d = x a + y b$。由于 $a, b in (d)$，$d mid a$ 与 $d mid b$ 都成立。若 $c$ 是 $a$ 与 $b$ 的因子，则 $c mid x a + y b = d$，故 $d$ 是 $a$ 与 $b$ 的一个最大公因数。

唯一性。若 $d'$ 是另一个最大公因数，则 $d mid d'$ 且 $d' mid d$，故 $d tilde d'$。证毕。

**PID 的好性质（续）**

**推论**
若 $R$ 是 PID，则每一个不可约元都是素的。

**证明**
令 $p in R$ 不可约，并假设对某个 $a, b in R$ 有 $p mid a b$。若 $p$ 不整除 $a$，则 $gcd(p, a) = 1$，于是我们可以写 $1 = x a + y p$ 对某个 $x, y in R$。因此 $b = (x a + y p) b = x (a b) + (y b) p$。由于 $p mid x(a b)$ 且 $p mid (y b) p$，于是 $p mid x(a b) + (y b) p = b$。证毕。

并不奇怪，最小公倍数在 PID 中也有很好的刻画。

若 $R$ 是 PID，则任意 $a, b in R^ast$ 都有一个最小公倍数 $m = "lcm"(a, b)$。它在相差相伴的意义下唯一，并且可以刻画为理想 $I := (a) inter (b)$ 的一个生成元。

**唯一分解整环**

**定义**
一个整环是 *唯一分解整环*（UFD），如果：

(i) 每一个非零元素都是不可约元的乘积；

(ii) 每一个不可约元都是素的。

**例子**
1. $ZZ$ 是 UFD：每一个整数 $n in ZZ$ 都可以唯一地分解成不可约元（素数）的乘积：$n = p_1^(d_1) p_2^(d_2) dots.c p_k^(d_k)$。这就是算术基本定理。
2. 环 $ZZ[x]$ 是 UFD，因为每一个多项式都可以分解成不可约元。但它不是 PID，因为下列理想不是主理想：$(2, x) = {f(x) : "常数项为偶数"}$。
3. 环 $R_(-5)$ 不是 UFD，因为 $9 = 3 dot 3 = (2 + sqrt(-5))(2 - sqrt(-5))$。
4. 我们已经证明 (ii) 对 PID 成立。接下来我们将看到 (i) 也对 PID 成立。

**唯一分解整环（续）**

**定理**
若 $R$ 是 PID，则 $R$ 是 UFD。

**证明**
我们需要证明条件 (i) 成立：每一个元素都是不可约元的乘积。一个环是 *诺特的*，如果每一条上升的理想链 $I_1 subset.eq I_2 subset.eq I_3 subset.eq dots.c$ 都稳定，意思是对某个 $k$ 有 $I_k = I_(k+1) = I_(k+2) = dots.c$。

假设 $R$ 是 PID。不难证明 $R$ 是诺特的（家庭作业）。定义 $X = {a in R^ast without U(R) : a "不能写成不可约元的乘积"}$。若 $X eq.not nothing$，则取 $a_1 in X$。把它分解为 $a_1 = a_2 b$，其中 $a_2 in X$ 且 $b in.not U(R)$。则 $(a_1) subset.neq (a_2) subset.neq R$，并重复这一过程。我们得到一条不稳定的上升链 $(a_1) subset.neq (a_2) subset.neq (a_3) subset.neq dots.c$。这在 PID 中是不可能的，因此 $X = nothing$。证毕。

## 第 36 页 / 46

**欧几里得算法**

大约公元前 300 年，欧几里得在他著名的《几何原本》中描述了如今所谓的欧几里得算法：

**命题 VII.2（《几何原本》）**
给定两个并非互素的数，求它们的最大公度量。

该算法之所以有效，是由于两个关键观察：若 $a mid b$，则 $gcd(a, b) = a$；若 $a = b q + r$，则 $gcd(a, b) = gcd(b, r)$。

用一个例子看得最清楚：令 $a = 654$，$b = 360$。

- $654 = 360 dot 1 + 294$，故 $gcd(654, 360) = gcd(360, 294)$；
- $360 = 294 dot 1 + 66$，故 $gcd(360, 294) = gcd(294, 66)$；
- $294 = 66 dot 4 + 30$，故 $gcd(294, 66) = gcd(66, 30)$；
- $66 = 30 dot 2 + 6$，故 $gcd(66, 30) = gcd(30, 6)$；
- $30 = 6 dot 5$，故 $gcd(30, 6) = 6$。

我们得出 $gcd(654, 360) = 6$。

**欧几里得整环**

粗略地说，欧几里得整环是欧几里得算法仍然有效的任意环。

**定义**
整环 $R$ 是 *欧几里得的*，如果它有一个次数函数 $d : R^ast -> ZZ$，满足：

(i) 非负性：对所有 $r in R^ast$ 有 $d(r) >= 0$。

(ii) 单调性：对所有 $a, b in R^ast$ 有 $d(a) lt.eq d(a b)$。

(iii) 带余除法性质：对所有 $a, b in R$，$b eq.not 0$，存在 $q, r in R$，使得 $a = b q + r$，并且 $r = 0$ 或 $d(r) < d(b)$。

注意性质 (ii) 可以改述为：若 $a mid b$，则 $d(a) lt.eq d(b)$。

**例子**
- $R = ZZ$ 是欧几里得的。定义 $d(r) = |r|$。
- 若 $F$ 是域，则 $R = F[x]$ 是欧几里得的。定义 $d(f(x)) = deg f(x)$。
- 高斯整数 $R_(-1) = ZZ[sqrt(-1)] = {a + b i : a, b in ZZ}$ 是欧几里得的，次数函数为 $d(a + b i) = a^2 + b^2$。

**欧几里得整环（续）**

**命题**
若 $R$ 是欧几里得的，则 $U(R) = {x in R^ast : d(x) = d(1)}$。

**证明**
“$subset.eq$”：首先，我们将证明相伴元有相同的次数。取 $R^ast$ 中的 $a tilde b$：$a mid b$ 蕴涵 $d(a) lt.eq d(b)$，$b mid a$ 蕴涵 $d(b) lt.eq d(a)$，因此 $d(a) = d(b)$。若 $u in U(R)$，则 $u tilde 1$，于是 $d(u) = d(1)$。

“$supset.eq$”：假设 $x in R^ast$ 且 $d(x) = d(1)$。则 $1 = q x + r$ 对某个 $q in R$，并且或者 $r = 0$，或者 $d(r) < d(x) = d(1)$。若 $r eq.not 0$，则由于 $1 mid r$ 有 $d(1) lt.eq d(r)$。因此 $r = 0$，于是 $q x = 1$，故 $x in U(R)$。证毕。

**命题**
