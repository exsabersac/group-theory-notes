# 与范畴论、编程的衔接

这一节是**支线**。群论主线仍是：定义、子群、同态、作用、结构定理。只有在同态与单位元、逆元已经用得比较顺之后，再回头看这里的观点，会更有收获。喜欢 Haskell 或范畴论的读者可以把它当作「同一对象的另一种语言」，而不是另一门要抢进度的课。

## 范畴论里的群

一个群 \(G\) 可以看成**只有一个对象的群胚**（groupoid）：

- 只有一个对象，记作 \(\bullet\)；
- 从 \(\bullet\) 到 \(\bullet\) 的态射就是 \(G\) 的元素；
- 态射的合成就是群的乘法；
- 每个态射都可逆，逆态射对应群中的逆元。

在这个看法下：

- 群同态 \(G\to H\) 正好是这个单对象群胚之间的函子；
- 单位元是恒等态射；
- 「结合律」就是范畴里合成的结合律。

若把「每个态射可逆」这条去掉，得到的是单对象范畴，也就是**幺半群**（monoid）。群是「每个元素都有逆的幺半群」。再把对象变多，就得到群胚；这是把群「水平范畴化」的第一步。

更仔细的术语与图表，可参考 nLab 词条 [group](https://ncatlab.org/nlab/show/group)（英文；写得抽象，适合已经知道定义的人对照，不适合当作入门教材）。不要指望只读这个词条就能学会 Sylow 或分类定理——范畴语言改写的是定义，不是整门课的定理表。

## 在 Haskell 里看到的群

Haskell 预导里最常见的是幺半群：`Monoid`（结合的二元运算加上单位元）。群比幺半群多一个逆。Hackage 上的 [groups](https://hackage.haskell.org/package/groups) 包提供了 [`Data.Group`](https://hackage.haskell.org/package/groups-0.5.3/docs/Data-Group.html)，在 `Monoid` 之上要求 `invert`（以及由此得到的整数次幂等操作），并区分交换情形的 `Abelian` 一类约束。

建议的对照方式（保持很小的范围）：

1. 先用数学定义写出 \((\mathbb{Z},+)\)、非零有理数乘法群、有限置换群的运算、单位元与逆；
2. 再看 `Group` 类型类的方法是否正好对应这三件东西；
3. 想一想：为什么 Haskell 生态里 `Monoid` 远比 `Group` 常见？（很多编程里的组合结构有单位元和结合律，却没有逆，例如列表的拼接。）

不要把类型类实例推导或某个具体包的 API 细节当成群论本身。包的版本会变，数学定义不会。
